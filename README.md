# SSMS-Management

## Introduction

**SSMS-Management** is a collection of T-SQL scripts designed to assist with managing and analyzing production data, particularly in a manufacturing or operational context. The repository organizes various report queries—such as line efficiency, attendance, workshop summaries, QC progress, and more—into a centralized toolkit, making it easier to generate insights quickly and consistently.

## Tech Stack

- **T-SQL (Transact-SQL)** – All scripts are written purely in T-SQL, offering powerful data querying and report-generation capabilities directly within Microsoft SQL Server environments.
- **SQL Server Management Studio (SSMS)** – Intended for use within SSMS, enabling users to run, review, and export results from these scripts seamlessly.
